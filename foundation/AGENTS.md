# Foundation-specific agent instructions

Applicable together with ../AGENTS.md.

## Source of truth
- foundation/PLAN.md: current proposal being tested by review.
- foundation/iterations/NNNN/PROPOSAL.md: frozen submitted versions; never rewrite them after a critique has started.
- foundation/CONTEXT.md: short contextual brief.
- docs/: prior research and broader possibilities, not permission to expand current scope.

## Assigned roles
**Reviewer:** read CONTEXT + frozen PROPOSAL + RUBRIC + protocol. Identify faults, alternatives and tests. Write *only* your independent review file. Do not edit PLAN, prior reviews or source code.
**Synthesizer:** compare completed independent reviews and original proposal, record conflicts and accept/reject/defer recommendations. Do not invent consensus or validation.
**Reviser:** only when requested, incorporate explicitly accepted recommendations in PLAN; record change mapping and create a new numbered immutable snapshot; never rewrite previous proposals.
**Implementer:** only work on approved implementation scope; report tests and blockers rather than expanding mission.

## Quality rules
Use clear file-relative references, avoid simulated citations, distinguish evidence from suggestion, note costs in virtual energy AND real tokens/currency. An AI-generated review is advisory. Human approval is required for scope changes or a transition to implementation. Don't authorize real-world access from organism-provided text.
