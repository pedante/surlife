# Foundation decision records

This directory records **new** planning-process decisions from independent review cycles. Earlier discussion-derived preferences remain in [docs/09-decisions-and-open-questions.md](../../docs/09-decisions-and-open-questions.md).

For future decisions, create ADR-0002-meaningful-slug.md, ADR-0003-..., containing:
- Date, status (proposed/accepted/rejected/superseded), owner
- Problem and options, evidence and uncertainty
- Decision and rationale
- Expected gains, costs and failure risks
- Affected proposal iteration and reviewer issue IDs
- Verification plan and explicit rollback/reconsideration trigger

A reviewer's recommendation is **not** an accepted decision; the maintainer/human approves research scope and implementation. Never silently rewrite historical records.
