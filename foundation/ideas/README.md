# Idea incubator — future hypotheses, not current requirements

Use this folder for speculative ideas worth preserving without inflating the current minimum experiment. New reviewers may suggest ideas here, but **an idea does not enter PLAN.md automatically**.

Every idea should include:
- Problem or observation inspiring it
- Mechanism hypothesized
- Minimal test that could disprove it
- Required prior milestone / interfaces
- Estimated extra engineering, real-token and simulation cost
- Risks to scientific interpretability
- Status: proposed / deferred / testing / accepted / rejected
- Related issues, sources and iterations
