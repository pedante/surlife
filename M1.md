# Surlife M1 — bounded editable LLM souls with OpenRouter Free

**Experimental stage.** M1 is a small local harness, not a general autonomous agent, self-improving verified model or safe code-execution sandbox. Work is restricted to the referee's bitmask task API.

## Quick start in Fish (CachyOS / Arch)

From your Surlife repository after checking out the M1 branch:

```fish
source .venv/bin/activate.fish
python -m pip install -e '.[test]'
pytest -q
surlife --seed 7 --ticks 8 --a llm --b greedy --provider fake --max-requests 4
```

That last command uses a deterministic **fake provider**. It does not use OpenRouter or need a key; it tests souls, provider accounting and replay.

To run actual free inference, create your key at https://openrouter.ai/settings/keys and read it into your Fish environment **without pasting it into command history**:

```fish
read --silent --prompt-str 'OpenRouter API key: ' OPENROUTER_API_KEY
set -gx OPENROUTER_API_KEY $OPENROUTER_API_KEY
surlife --seed 7 --ticks 8 --a llm --b greedy --provider openrouter --model openrouter/free --max-requests 4
```

Use `set -e OPENROUTER_API_KEY` to remove the Fish variable when finished. Never put the key in a soul, Git file or chat. **Live inference has not been exercised by the automated tests** and requires an actual account/API key.

The default `openrouter/free` is the documented zero-priced Free Models Router. It **randomly selects among available free models**, so runs can differ for reasons other than evolving soul quality. For scientific comparisons, select and record one currently available explicit `provider/model:free` slug (verify availability at https://openrouter.ai/collections/free-models). The gateway rejects model slugs not ending in `:free` unless exactly `openrouter/free`. There is no automatic paid fallback. Free tier quotas and providers' availability may change; check https://openrouter.ai/docs/api-reference/limits and your account limits.

## What an M1 organism actually owns

- **Soul:** separate versioned system-strategy text per actor, optionally loaded from `--soul-a path.txt` or `--soul-b path.txt`. A model may propose at most three compact strategy-note revisions, only after an objectively imperfect attempt. Proposals are appended for later ticks, **not** independently evaluated or known to improve fitness.
- **Memory:** up to eight recent task-result records per organism. Only four records enter a new prompt. No opponent private data is exposed.
- **Action:** one data-only JSON object (`{"mask": 9, "soul_update": "Compare combinations."}`), where bit `i` selects task item `i`. The trusted referee validates and scores it. No executable Python, shell, network tool or economic authority is attached to organism output.
- **Consultation:** one virtual-energy unit per admitted request, even if it errors. A host gateway applies `--max-requests` (default 6) and `--max-output-tokens` (default 128, maximum 512). Calls are serialized; no automatic retries. If a call fails, budget is exhausted or energy is too low, a **trusted Greedy fallback** acts; its turns are distinguishable in journal metadata.
- **Provider metadata:** actual routed model and provider-reported input/output tokens (possibly missing), failure status and soul versions recorded per tick. The API key and raw response/prompt are not persisted. Replay reuses submitted actions, never resends a model request.
- **Persistence:** `out/souls/<run_id>/a.json` and/or `b.json` store data-only soul versions, notes and memory; `out/surlife.sqlite` holds the immutable round ledger. A crashed M1 session is **not resumable**; choose a new run ID. Replay checks the world ledger, not faithful regeneration of prompt text or model outputs.

## Examples

```bash
# Both actors LLM-based, four paid-in-virtual-energy consultations maximum across them:
surlife --a llm --b llm --provider openrouter --max-requests 4 --ticks 12

# Pin a known zero-priced :free model to reduce routing confounds:
surlife --a llm --b greedy --provider openrouter --model example/provider:free

# Replay needs no API key (replace ID with the one printed by your run):
surlife --replay YOUR_RUN_ID
```

The pinned-model command contains an **illustrative placeholder**; replace `example/provider:free` with a currently listed model slug. By default, the other actor remains Optimal if `--b` is omitted; this example explicitly picks Greedy.

## Scientific interpretation and next tasks

One prompt revision is **not** evidence of selection or improvement. The fake provider is a deterministic protocol test double, not a real LLM. Before claiming adaptation, run matched-seed static-soul versus mutable-soul versus random-revision controls, maintain held-out puzzle families, report actual requested/served models, unknown billing, model usage and all setup/trial costs, and explicitly separate direct correctness from energy survival. The Free Models Router is better for trying the system than for controlled comparative studies.

**Deferred:** paid models, provider-independent hard monetary billing caps, arbitrary tool use, Python code mutation/sandboxing (M2), GEPA integration, reproduction, multi-world scientific confidence analysis. This is a locally controlled M1 pilot; it never executes model-generated code.
