# Surlife M1.6 — adaptive cognition, not a fixed consultation schedule

**Opt-in:** `surlife --m16`. Builds on the exact M1.4 `m14-v1` task
streams, trusted M0-v2 referee, consulted Gemini/OpenRouter/fake gateways and
transaction rules, without changing historical M0–M1.5 runs.

## What evolves

The organism has two *data-only* contexts (`uncertain`, `routine`), derived
from the visible item costs, rewards and the cheap Greedy result. For each
context it remembers the number of visits, paid consultations and observed
**one-tick energy gain versus the same no-consultation Greedy action**.

The first encounter explores, positive observed mean gain encourages subsequent
consultations, and a bounded periodic probe permits re-evaluation of previously
unprofitable decisions. A consultation is permitted only if the trusted gateway
still has requests, energy after upkeep can afford the charge and the organism
has at least six energy. A 429 stops further calls in that run. Failed
consultations are charged only when actually attempted; no retries or
unbounded calls occur.

The policy never sees future tasks, the generated `trap` label, optimal
solutions, opponent secrets or code. **Only predefined trusted Python is
executed; the evolving entity is a bounded JSON-compatible strategy state,
not self-modifying source code.** No model is called to decide whether to
call a model; the organism has a cheap deterministic metacognitive policy.
The feedback is calculated *after* settling the real decision from a
single-tick shadow referee starting from the identical prior ledger, with the
same opponent action, but selecting Greedy and paying no consultation cost.

The result is an **on-policy online-learning experiment**, not evidence of
emergent general intelligence. M1.4 exact DP still cheaply solves this
knapsack domain; it is an unpriced diagnostic, not a physically free agent.

## Run without any account or real requests

```fish
python -m pip install -e '.[test]'
pytest -q tests/test_m16_m17.py
surlife --m16 --a llm --b greedy --provider fake \
  --seed 17 --benchmark-cases 12 --benchmark-items 12 \
  --max-requests 4 --benchmark-out out/m16-fake-17.json
surlife --verify-adaptive-file out/m16-fake-17.json
```

For a real Gemini comparison, verify the project is on Google's free billing
tier first and set `GOOGLE_API_KEY` privately. A free-tier model listing does
not verify actual account billing. One command with four maximum calls:

```fish
surlife --m16 --a llm --b greedy --provider google \
  --seed 17 --benchmark-cases 12 --benchmark-items 12 \
  --benchmark-profile mixed --max-requests 4 \
  --max-output-tokens 4096 --reasoning off \
  --benchmark-out out/m16-google-17.json
surlife --verify-adaptive-file out/m16-google-17.json
```

Compare `summary.arms.llm` with the already available M1.4 never,
selective and always controls under matched seeds and consultation budgets.
Model responses vary across independent live runs; one seed is not a
statistical effect estimate.

## Audit

The saved report uses the old `m14-v1` referee schema plus opt-in
`experiment=m16-v1`, `policy_initial` and per-tick `policy_decision`,
`net_energy_vs_greedy`, `policy_after`. The independent verifier checks
referee actions/transfers, call accounting, task hashes, bounded policy
decisions, counterfactual reward and the evolved state. SHA-256 content
hashes detect accidental report inconsistencies; they are not signatures
protecting against someone who can edit and recompute all the evidence.
Raw model completions and API keys are never persisted.

**M1.7** uses these reports for a held-out inheritance experiment; see
[M17.md](M17.md).
