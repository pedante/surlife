# Surlife project instructions for Claude and other assistants

Read [AGENTS.md](AGENTS.md), [foundation/README.md](foundation/README.md), and [foundation/PLAN.md](foundation/PLAN.md) before editing this repository.

When the task is **critique**, use [foundation/prompts/REVIEWER.md](foundation/prompts/REVIEWER.md) and write an independent review under the current iteration. Do not edit the proposal.

When the task is **synthesis**, use [foundation/prompts/SYNTHESIZER.md](foundation/prompts/SYNTHESIZER.md); when the task is **revision**, use [foundation/prompts/REVISER.md](foundation/prompts/REVISER.md).

Research proposals are not implemented features. Preserve Git history and avoid modifying unrelated project files.
